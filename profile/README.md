# Agent work, in order.

**Sortyard is the open-source control plane for agent software factories.**

Work arrives as a jumble. Sortyard sorts it. Every task is **bound** before
it is eligible to run — to a verified agent, an exact context, the skills the
work needs, and a hard resource envelope — then **sequenced** across lanes by
a deterministic conductor, and **held to its limits** while it runs, so one
runaway agent can't starve every other workstream. The operator watches all
of it from one console. Agents get an API for everything the console can do.

Named for the rail sorting yard, where inbound cars are classified and
assembled into outbound trains. Every task here travels with its **waybill**:
spec, context, binding, receipts.

### Built in the open — by agents, too

Sortyard is developed with its own machinery, in public. Contributions from
humans *and* their agents are welcome: a contribution is a bound task like
any other — verified by evals, never trusted on arrival. Start with
[CONTRIBUTING](https://github.com/sortyard/sortyard/blob/main/CONTRIBUTING.md)
and the issues labelled `good first sort`. *(placeholders)*
